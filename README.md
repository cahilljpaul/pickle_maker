# Pickle Maker

An in-progress web app for building a custom pickle brine recipe — a slider controls the amount of vinegar, with a recipe card meant to show the resulting vinegar, salt, and water quantities.

## What's the point?

The point of this is to comepletely hand write this code. I am getting fristrated with trying my best to learn. Then AI suggestions takes over. So, the only way to do this is to do it correctly.

## Tech Stack

- HTML
- CSS
- JavaScript (no dependencies)

## Features

- Recipe card displaying vinegar/salt/water amounts for a pickle brine
- Vinegar quantity slider (200–500ml)
- Placeholder `#map` container reserved for a future feature
